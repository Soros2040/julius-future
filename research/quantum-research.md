# 量子核自设计与风险增强组合优化

状态：研究设计与预立项。本文定义研究问题、实验约束和拟交付的证据。

## 1. 需要解决的问题

量子核自设计需要在候选特征映射、线路结构和连续参数中寻找有效组合。每次候选评估可能涉及核矩阵估计、模拟或真实测量；有限 shots、噪声与编译开销又会使理想条件下的选择发生变化。

核心研究问题是：**在可核算的评估预算下，如何找到预测质量、稳定性和硬件资源之间更合适的量子特征映射？** 金融风险任务用于检验这种选择是否能改善下游决策。

## 2. 方法链路

```text
按时点可见的数据与动态资产集合
  → 特征筛选和量子核候选
  → 候选评分、排序与连续参数优化
  → 共享局部量子消息线路及风险图聚合
  → 收益与风险参数 μ、B、d
  → QUBO / Ising 目标与组合约束
  → QAOA 组合候选
  → 硬件感知筛选与执行证据
```

QuKerNet 提供量子特征映射搜索的研究起点。风险图、组合接口及硬件执行链路分别验证其新增贡献。

应用目标采用动态沪深 300 资产图，以日频决策、下一交易日执行、选择 5 个资产及等权配置作为初始研究设计。300 表示图节点数；局部线路规模按模拟与硬件预算确定。

## 3. 首个可复现实验

先在允许分发的合成数据和小规模任务上验证实验流程，再使用具有合适许可的金融数据开展时间外评价。

1. 冻结数据生成或预处理、训练验证测试划分、种子集合、搜索空间及预算。
2. 对照经典线性或 RBF 核、固定量子映射、随机线路搜索和 QuKerNet 式候选筛选。
3. 在同一总评估预算下记录候选评估次数、核估计开销、预测指标和跨种子方差。
4. 分开报告理想模拟、有限 shots、噪声模拟；资源具备后再记录真实后端实验。
5. 消融特征筛选、候选排序和连续参数优化，确定改善来自哪一部分。

该实验的首要交付是可复现配置和完整对照结果；下一阶段的选择依据这些结果做出。

## 4. 下游评价与接口约束

| 阶段 | 必须一致的条件 | 评价内容 |
| --- | --- | --- |
| 数据 | 决策时点、资产轴、标签期限、可见性 | 缺失与泄漏检查、时间划分 |
| 风险预测 | 收益单位、风险定义和预测期限 | 时间外 RMSE / MAE、稳定性 |
| 风险参数 | μ、低秩风险因子 B、残差项 d 的含义 | 维度、有限值、非负残差和轴一致性 |
| 组合优化 | 相同目标、硬约束、换手与成本口径 | 可行率、CVaR、回撤、净收益 |
| 硬件执行 | 编译版本、拓扑、校准与 shots | 双量子比特门数、深度、SWAP、目标质量 |

风险预测至少与 Ridge / FEVD、经典图方法和去掉量子模块的版本比较。组合阶段先在小问题上以枚举或精确求解检查目标与约束，再与适用的经典优化方法比较。

所有数据按当时可见信息构建。训练、验证、测试按时间分离，并根据标签期限设置 purge / embargo。交易成本、停牌、涨跌停和流动性处理在正式实验前冻结。

## 5. 预注册评价目标

以下数值用于规划正式实验；在数据访问、资源预算和实验合同确认后冻结，随后同时报告达到与未达到的结果。

| 维度 | 目标 |
| --- | --- |
| 时间外风险预测 | 相对最强经典基线，RMSE / MAE 改善至少 5%，同时报告置信区间 |
| 风险增强组合 | CVaR 或最大回撤改善至少 5%，净收益不劣化，硬约束满足率 100% |
| 硬件可执行性 | 编译后双量子比特门数、深度或 SWAP 至少下降 10%，目标质量下降不超过 1% |
| 稳定性 | 跨随机种子、时间外窗口及至少 3 个独立校准块复核 |
| 证据完整性 | 数据、线路、编译、测量、评价与决策结果可关联并复现 |

每项比较都需说明基线选择、样本量、预算和不确定性。是否存在量子优势需要独立、资源公平的证据，不能从单次改善推定。

## 6. 里程碑与证据

- **核搜索基线**：实现与环境说明、固定配置、对照表、预算统计和复核记录。
- **风险与组合桥接**：数据时点检查、轴和单位验证、目标函数一致性、约束测试。
- **硬件评估**：后端信息、线路与编译记录、采样结果、失败记录和资源报告。
- **教育交付**：围绕已验证模块编写概念讲解、最小示例、练习和常见问题。

达不到预设目标时，记录适用边界及原因，再通过 Issue 决定调整方法或结束该实验方向。具体数据、实现与测量以对应成果的版本为准。
