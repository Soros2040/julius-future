## First contribution

Choose one claim in a project or research note. Read its linked source, record the exact section or table, and explain whether it supports the wording and scope. Open an Issue using the [contribution guide](CONTRIBUTING.md), then submit a focused PR. An evidence review does not require a GPU.

The [learning guide](docs/learning-and-writing.md) includes a completed example. [Maintenance](docs/maintenance.md) explains review and handoff. [Reading sources](docs/reading-sources.md) identifies the material that informs the reflection.
