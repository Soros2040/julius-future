# 关于 Julius' future

Julius' future 记录个人项目、思考与未来工作。“过去”连接一年内探索的三个项目，“思考”从经历和阅读中展开问题，“未来”把开放问题转换为范围明确的任务，其中包括量子特征映射研究方案。

读者可以沿着[项目回顾](past.zh-CN.md)、[原创随笔](reflections.zh-CN.md)或[路线图](roadmap.zh-CN.md)阅读；研究读者可直接查看[方案](../research/quantum-research.md)与[题录](../research/references.md)；贡献者可以从[学习指南](learning-and-writing.zh-CN.md)中的来源复核开始。

项目由 Julius 维护。具体研究成果对应各自的来源项目与版本，个人反思表达作者的理解，社区关系通过贡献及其实际产物来记录。
