# 路线图

按证据完成程度推进里程碑。日期和负责人在认领任务时写入 Issue，依赖未满足时先更新状态。

| 里程碑 | 当前状态 | 验收条件 |
| --- | --- | --- |
| M0：项目基础 | 已完成 | 定位、研究方案、参考入口、贡献和交接规范可阅读 |
| M1：核搜索最小实验 | 计划中 | 经典核、固定量子核、随机搜索和候选筛选可在同一预算下比较 |
| M2：风险预测与组合桥接 | 计划中 | 数据时点、资产轴、单位和目标一致，基线及约束检查可复现 |
| M3：硬件资源评价 | 计划中 | 理想、采样及噪声结果分开记录，真实后端实验具备完整回执 |
| M4：学习材料 | 计划中 | 已验证模块具备说明、练习和另一位读者的复现反馈 |
| M5：持续维护 | 流程已定义 | 第二位维护者完成一次独立复现、审阅与交接演练 |

## 首批可认领任务

1. 核对研究方案中的基线和引用，提出遗漏或不公平比较。
2. 将 M1 拆成数据、实验框架、基线和评价四类可验收任务。
3. 明确可分发的最小数据、固定预算和种子集合。
4. 设计实验结果记录格式，并用一个经典基线检验流程。
5. 为量子核与时间序列验证整理前置知识清单。

## 成果登记

每项成果记录标题、贡献者、关联 Issue / PR、版本、复现入口、证据与状态。建议状态为：计划中、进行中、待复核、已复核、已归档。

每个里程碑完成时更新本页与 README。只有存在实际成果及验收记录时才标记完成。
