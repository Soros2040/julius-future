# 学习与写作指南

学习内容跟随研究问题组织。先解释为什么需要一个概念，再用可复现的最小例子帮助读者理解其作用。

## 推荐学习顺序

1. 研究设计：假设、基线、预算、公平比较和不确定性。
2. 核方法：特征映射、核矩阵、核目标对齐和模型选择。
3. 量子基础：参数化线路、测量、有限 shots 与噪声。
4. 时间序列评价：数据时点、标签期限、时间外验证和泄漏。
5. 图与风险：图消息传递、低秩风险表示及评价。
6. 组合优化：约束、QUBO / Ising、经典求解和 QAOA。

## 章节结构

每篇学习材料围绕一个问题组织：

- 开头说明背景、前置知识和学习目标。
- 正文定义符号，解释方法，连接到实际问题。
- 最小示例给出输入、预期行为和运行条件。
- 结尾概括局限，给出练习或可验证的问题。
- 参考资料列出实际使用的原始来源。

研究笔记需要进一步区分已知结论、自己的假设、实际结果及解释。保留失败的实验条件，便于后来者判断适用范围。

## 写作与反馈

先完成一个能够独立阅读的小节，再邀请他人复现或提问。根据反馈修正缺失步骤、符号和歧义。AI 可以辅助整理，作者对事实、来源和表达负责。

通用写作成果可采用“问题—背景—证据—推理—结论—局限”的结构。公开发布前核对授权范围、引用和署名，具体提交流程见[贡献指南](../CONTRIBUTING.md)。
