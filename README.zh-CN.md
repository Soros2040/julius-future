## 当前进展

项目回顾与原创思考已经形成可阅读正文。量子核方向处于**研究设计与预立项阶段**，目标改善幅度用于规划实验。Datawhale 与实验室协作是我希望继续发展的路径，具体身份和贡献通过实际产出或公开贡献链接记录。

## 第一次参与

从项目介绍或研究笔记中选一条表述，阅读其原始来源，记录具体章节或表格，说明来源能够支持的内容与范围。按照[贡献指南](CONTRIBUTING.zh-CN.md)创建 Issue，再提交一个集中的 PR。资料复核无需 GPU。

[学习指南](docs/learning-and-writing.zh-CN.md)提供完整示例；[维护说明](docs/maintenance.zh-CN.md)解释审阅与交接；[阅读来源](docs/reading-sources.zh-CN.md)列出影响个人思考的材料。
